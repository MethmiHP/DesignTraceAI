DESIGNTRACE AI
AI-ASSISTED DATABASE DESIGN MODULE
NLP MODEL COMPARISON AND EVALUATION SUMMARY

============================================================
1. EVALUATION OBJECTIVE
============================================================

Compare three transformer-based named entity recognition (NER)
models for extracting database-design concepts from software
functional requirements:

- ENTITY
- ATTRIBUTE
- ACTION

Models evaluated:
1. BERT (bert-base-uncased)
2. DeBERTa-v3-base (microsoft/deberta-v3-base)
3. RoBERTa-base (roberta-base)

The model outputs support the Database Design Module's
subsequent concept mapping and AI-assisted schema generation.
The scores below evaluate NLP concept extraction, NOT the
correctness of generated database schemas or end-to-end designs.

13. GENERALIZATION GAP
============================================================

Measured as:
Project-independent micro F1 - Real-world micro F1

BERT:            0.9807 - 0.8187 = 0.1620
DeBERTa-v3-base: 0.9769 - 0.6667 = 0.3102
RoBERTa-base:    0.9913 - 0.9153 = 0.0760

RoBERTa-base has the smallest observed gap across these two
sets. This is descriptive evidence of stronger performance on
the evaluated real-world sample; it does not establish broad
generalization to every software domain.

============================================================
14. SELECTED MODEL AND JUSTIFICATION
============================================================

SELECTED MODEL: RoBERTa-base

Reasons:
1. Highest project-independent micro F1: 0.9913.
2. Highest real-world micro F1: 0.9153.
3. Highest real-world ATTRIBUTE F1: 0.8219.
4. Highest real-world ENTITY F1: 0.9278.
5. Smallest observed cross-dataset micro-F1 drop: 0.0760.

RoBERTa-base is therefore selected for the NLP concept
extraction stage of the Database Design Module, based on the
reported comparison results.
