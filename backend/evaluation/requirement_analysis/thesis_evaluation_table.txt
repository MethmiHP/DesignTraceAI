Interpretation Notes

1. The FR/NFR classifier achieved an accuracy of 78.0% on the external reviewed evaluation set.

2. The standalone NFR category classifier achieved 44.0% accuracy, indicating weaker performance on fine-grained quality-attribute classification.

3. The end-to-end NFR classification chain achieved 32.0% accuracy because FR/NFR misclassification can prevent the NFR category classifier from being executed.

4. The rule-based ambiguity detector achieved high precision (100%) but low recall (38.46%). This indicates that deterministic rules are reliable when they flag an ambiguity, but they miss many contextual ambiguity cases.

5. The rule-based incompleteness detector achieved zero recall because the current rules mainly detect explicit placeholders such as TBD and TBA, while the reviewed evaluation set contains broader contextual incompleteness.

6. The results support the hybrid architecture combining deterministic rules, fine-tuned transformer classifiers, and LLM-based contextual reasoning.

7. Final hybrid end-to-end results will be added after the remaining Gemini-based evaluation projects are completed.
